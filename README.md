# EbeyParser

Круглосуточный охотник за выгодными б/у вещами на **Kleinanzeigen** (и **eBay.de** через официальный API).

Выбираешь город, радиус, категории (телефоны, ноутбуки, консоли, комплектующие…) и бюджет — программа сама просматривает **все новые объявления этих категорий** рядом с тобой и для каждого перспективного:

1. **оценивает рыночную цену** — по истории цен, которую копит сама, и по похожим объявлениям на Kleinanzeigen;
2. **показывает фото и описание локальной нейросети** (LM Studio или Ollama, у тебя на компьютере, бесплатно): что это за товар, совпадают ли фото с описанием, нет ли дефектов, блокировок, признаков развода или фото из интернета;
3. **считает чистую прибыль при перепродаже** (или экономию, если покупаешь для себя) и **до какой цены стоит торговаться**;
4. **присылает в Telegram или на почту** только то, что правда стоит купить, с объяснением почему.

Два режима: **перепродажа** (купить дёшево → продать по рынку) и **для себя** (например, собрать AI-сервер из б/у железа дешевле рынка).

> Всё работает **локально**: парсер и нейросеть — на твоём компьютере. Облачная модель (Claude) — необязательное «второе мнение», по умолчанию выключено.

## Быстрый старт (Windows)

1. Установи **Python 3.11+** с [python.org](https://www.python.org/downloads/) — при установке отметь **«Add python.exe to PATH»**.
2. Скачай проект (зелёная кнопка **Code → Download ZIP**) и распакуй, например, в `C:\EbeyParser` (не в OneDrive — см. ниже).
3. Дважды кликни `deploy\start-windows.bat`. Он сам поставит всё нужное, запустит **мастер настройки** и потом панель.

Или то же самое в PowerShell:

```powershell
cd C:\EbeyParser
python -m venv .venv
.venv\Scripts\activate
pip install -e .

python -m ebeyparser setup      # мастер: город, радиус, категории, бюджет, нейросеть, Telegram
python -m ebeyparser run        # панель http://localhost:8000 + проверки 24/7
```

**Мастер настройки** (2 минуты) спрашивает по-русски: город или индекс, радиус (по умолчанию 30 км), какие категории сканировать (номера через запятую, по умолчанию — набор для перепродажи), цель, максимальную цену за вещь, минимальную прибыль, список «для себя» (например «RTX 3090» до 550 €), как часто проверять, сам находит LM Studio/Ollama и vision-модель, и (по желанию) подключает Telegram. Токены пишутся в `.env`, а не в `config.yaml`; комментарии в `config.yaml` сохраняются, старая версия — в `config.yaml.bak`.

То же самое есть в панели: страница **«Настройка»** (http://localhost:8000/setup), а нейросеть, Telegram и пороги выгоды — на вкладке рядом (`/settings`).

Хочешь сначала просто посмотреть интерфейс? `python -m ebeyparser demo`, затем `python -m ebeyparser run --no-monitor`.

## Обновление с прошлой версии

1. Останови программу (Ctrl+C) и обнови:
   ```powershell
   git pull
   pip install -e .
   ```
   `pip install` нужен: добавился Pillow — фото сжимаются перед нейросетью, LM Studio работает заметно быстрее. Если запускаешь через `deploy\start-windows.bat`, он сам заметит новую версию и доустановит пакеты. Если Pillow не хватает, программа напишет об этом при запуске и в `ai-check`.
2. База `data\ebeyparser.sqlite3`, `.env` и `config.yaml` сохраняются, новые таблицы создадутся сами.
3. Старые поиски по словам продолжают работать. Чтобы сканировать целые категории в своём районе, запусти мастер: `python -m ebeyparser setup`. Старый конфиг он сохранит как `config.yaml.bak`.
4. Первая проверка каждого **нового** поиска — «обучение»: программа собирает цены и ничего не присылает. Уведомления начинаются со следующей проверки.
5. Проверь нейросеть: `python -m ebeyparser ai-check`.

## Как это работает

```
 категории в радиусе (Kleinanzeigen) ─┐
 «для себя»: RTX 3090 до 550 €       ─┼─► новые объявления ─► фильтр (Suche/Tausch/defekt, цена, мусор)
 eBay (официальный API, по желанию)  ─┘        │
                                               ▼  воронка: дальше только перспективные
                            оценка рынка: своя история цен → похожие объявления (→ продажи eBay, если доступны)
                                               │
                                               ▼
                            страница объявления (текст + все фото) → локальная нейросеть
                                               │
                                               ▼
                            прибыль, ROI, «выгодно до X €», оценка 0–100, вердикт
                                               │
                              ┌────────────────┼───────────────┐
                              ▼                ▼               ▼
                         веб-панель        Telegram          e-mail
```

- **Первая проверка нового поиска — «разведка»**: программа изучает цены в категории и **не присылает уведомлений** о том, что уже висело на сайте. Уведомления начинаются со следующей проверки — только о новых объявлениях.
- Повторно объявления не присылаются; при **снижении цены на 10 %+** объявление оценивается заново.
- Проданные на eBay (`use_ebay_sold_comps`) — хороший ориентир, но eBay часто закрывает эти страницы защитой (HTTP 403). Тогда программа просто обходится без них.

## Сканирование категорий

Главный режим — не поиск по словам, а **все новые объявления категории** в радиусе от города. В `config.yaml` это выглядит так (мастер пишет это сам):

```yaml
searches:
  - name: "Handy & Telefon · Berlin 30 км"
    location: Berlin
    radius_km: 30
    category_id: 173
    min_price: 50          # отсекает чехлы и кабели
    max_price: 400         # твой бюджет на одну вещь
    exclude_keywords: [defekt, bastler, suche, tausch, ersatzteil]
```

`min_price` / `max_price` у сканирования категорий — фильтр уведомлений, а не поиска: объявления с ценой вне диапазона **не присылаются, но учитываются для оценки рынка** (история цен от этого точнее).

Номера категорий: `python -m ebeyparser categories` (встроенный справочник, без запросов к сайту). `python -m ebeyparser categories --live` сверяет его с сайтом для твоего города и показывает число объявлений (1–2 запроса, результат запоминается на 7 дней в `data/categories.json`); в панели — кнопка «Сверить с сайтом».

Рекомендуемый набор для перепродажи: Handy & Telefon (173), Notebooks (278), Konsolen (279), PC-Zubehör & Software (225), Foto (245), Audio & Hifi (172), Tablets & Reader (285).

Категория — это сотни объявлений, поэтому работает **воронка**: дешёвые проверки для всех, дорогие (страница объявления, поиск аналогов, нейросеть) — только для перспективных, в пределах лимитов за проверку (`general.max_details_per_run`, `max_comps_lookups_per_run`, `max_ai_per_run`). Не влезшее не теряется — оценится в следующей проверке. Каждая увиденная цена попадает в **историю цен**, поэтому со временем оценка точнее и требует меньше запросов.

### Сколько запросов делает мой конфиг

За одну проверку, обязательно: **каждая категория — до 3 страниц выдачи** (пока не встретятся уже знакомые объявления) плюс 1 переход с формы поиска; поиск по словам — `max_pages` страниц плюс переход. Дальше — только для перспективных объявлений: страница объявления (до `max_details_per_run` за проверку) и поиск цен аналогов (до `max_comps_lookups_per_run`, каждый ≈ 2–3 страницы). Сверху всё ограничено `general.max_requests_per_hour` (по умолчанию 150 в час на сайт).

Пример: 7 категорий + 1 поиск «для себя» = до 30 страниц выдачи за проверку. Раз в 30 минут это до 60 страниц в час, и на оценку объявлений остаётся ~90 запросов в час. Раз в 15 минут выдача съела бы 120 из 150 — на оценку почти ничего, объявления копились бы в очереди. Поэтому мастер и страница «Настройка» считают это для твоих настроек и предлагают интервал, при котором выдача берёт не больше 40 % лимита (для ~7 категорий — 30 минут), и предупреждают, если чаще. Очередь на оценку и «просроченные» объявления видны на странице «Статус».

### Если Kleinanzeigen заблокирует

При блокировке (HTTP 403/429, капча) программа **делает паузу, и она растёт**: 1 ч → 2 ч → 4 ч → 12 ч (`general.block_cooldown_hours`). Пауза переживает перезапуск, так что перезапуск не «пробивает» блокировку. Если блокировки повторяются — увеличь `interval_minutes` и уменьши число категорий.

## Бесплатная нейросеть в облаке

Нет хорошей видеокарты? Нейросеть может работать **в интернете бесплатно** — например, большая **NVIDIA Nemotron**
читает объявления и смотрит фото за пару секунд. Ничего устанавливать не нужно, только получить ключ.

1. Открой **Настройки → Нейросеть → «Где работает нейросеть»** и выбери **«Бесплатное облако»**
   (или **«Облако + компьютер про запас»**, если на компьютере уже есть LM Studio: когда бесплатный лимит
   кончится, продолжит модель на компьютере).
2. Выбери сервис и нажми **«Получить ключ»** — откроется страница, где его создать:

   | Сервис | Что бесплатно | Как получить ключ |
   |---|---|---|
   | **OpenRouter** | 20 запросов в минуту, **50 в день**; после **разовой** покупки $10 кредитов — **1000 в день** (бесплатные модели кредиты не тратят) | openrouter.ai → Keys → Create Key |
   | **NVIDIA** | около 40 запросов в минуту, **без дневного лимита** (условия «для пробы», без гарантий) | build.nvidia.com → бесплатный аккаунт NVIDIA Developer → API Keys |
   | **OmniRoute** | шлюз на твоём компьютере: сам переключается между бесплатными облаками | установи OmniRoute по инструкции на его странице; ключ не обязателен |

3. Вставь ключ и нажми **«Проверить»**. Программа проверит ключ, покажет бесплатные модели (рекомендуемые уже
   выбраны: Nemotron 3 Super — читать объявления, Nemotron Nano 12B VL — смотреть фото), свои лимиты и строку вроде
   «Ключ работает · 20 запросов в минуту · 50 в день · ответ за 2,1 с · хватит на ~800 объявлений в день».
4. Нажми **«Сохранить»**. Расход за сегодня видно в **Состояние → «Облако»**.

Ключ хранится только на этом компьютере (в файле `.env`), в настройках он скрыт. В облако уходят только название,
описание, цена, характеристики и фото объявления — без имени и телефона продавца, без твоего адреса и заметок.
Объявления с eBay в облако не отправляются (так требуют правила eBay) — их смотрит компьютер про запас или обычная
проверка. Когда лимит на день кончился, программа не ждёт: разведчик читает только «непонятные» объявления, а фото
лучших находок проверяются в первую очередь; остальное — как без нейросети, с пометкой «фото не проверены».
Для поиска по целым категориям 50 запросов в день мало — купи $10 кредитов один раз или возьми NVIDIA.
Подробности, лимиты и риски — `docs/design/CLOUD_AI.md`.

## Локальная нейросеть

### LM Studio (рекомендуется)

1. Установи **[LM Studio](https://lmstudio.ai)**. Во вкладке **Discover** скачай **Qwen3.5 9B** (`qwen/qwen3.5-9b`, вариант Q4_K_M; для видеокарты 6–8 ГБ — `qwen/qwen3.5-4b`). Какая модель подойдёт твоему железу — подскажет **Настройки → Нейросеть → «Выбери своё железо»**; подробности и замеры — `docs/design/AI_MODELS.md`.
2. Загрузи модель и поставь **Context Length не меньше 8192** (три фото занимают много токенов; при меньшем контексте модель обрезает запрос и отвечает ерундой).
3. Вкладка **Developer → Start Server** (или `lms server start`). В настройках включи автозапуск сервера, чтобы всё работало 24/7.
4. Мастер `setup` найдёт сервер сам. Вручную в `config.yaml`:
   ```yaml
   ai:
     enabled: true
     provider: openai
     base_url: http://localhost:1234/v1
     model: qwen/qwen3.5-9b
   ```
5. Проверка: `python -m ebeyparser ai-check` (покажет модели на сервере; `--fix` сам впишет найденную vision-модель).

Фото перед отправкой в модель уменьшаются — для этого ставится пакет **Pillow** (идёт вместе с программой; в старой установке: `pip install pillow`). Без него всё работает, но нейросеть заметно медленнее.

### Ollama (альтернатива)

```bash
ollama pull qwen3.5:9b-q4_K_M
```
и в `config.yaml`: `provider: ollama`, `base_url: http://localhost:11434`, `model: qwen3.5:9b-q4_K_M`.

| Твоё железо | Модель | Примерно памяти |
|---|---|---|
| Видеокарта 10–12 ГБ | Qwen3.5 9B (`qwen/qwen3.5-9b` / `qwen3.5:9b-q4_K_M`) — фото и немецкий текст за секунды | ~8 ГБ |
| Видеокарта 6–8 ГБ | Qwen3.5 4B (`qwen/qwen3.5-4b` / `qwen3.5:4b-q4_K_M`) | ~5 ГБ |
| Слабый ПК / без видеокарты | Qwen3.5 2B (`qwen/qwen3.5-2b` / `qwen3.5:2b-q4_K_M`) | ~3 ГБ; на процессоре ~40 с на фото, поставь `timeout_seconds: 400` |
| 24 ГБ (например, RTX 3090) | Qwen3.6 35B-A3B (`qwen/qwen3.6-35b-a3b`) — текст и фото одной моделью | ~22 ГБ |

Уже работающая модель (например, Qwen2.5-VL-7B) остаётся как есть — программа никогда не меняет выбранную тобой модель.

### ИИ-разведчик: нейросеть читает каждое объявление

Скрипт отбирает объявления по названию и истории цен — и не видит «alter PC» с RTX 3080 внутри, «Iphne 13»,
«Konvolut» или продавца, который не знает, что продаёт. **Разведчик** — маленькая текстовая модель (2–4B), которая
читает **каждое** новое объявление (название, цену, начало текста) и говорит, что это на самом деле: модель, что внутри
комплекта, опечатки, риски, насколько интересно. **Цены она не придумывает**: деньги считаются только по истории цен и
похожим объявлениям, а все прежние проверки (фото, дефекты, развод) остаются. Находки разведчика помечены
«Нашла нейросеть».

Разведчик может жить на слабом домашнем сервере без видеокарты (llama.cpp / Ollama / LM Studio): **Qwen3.5 2B**
(`qwen3.5:2b-q4_K_M` в Ollama, `qwen/qwen3.5-2b` в LM Studio) читает ≈ 6 с на объявление (~600 в час) на мини-ПК
вроде N100, **Qwen3.5 4B** точнее, но ≈ 15 с (на 8 ядрах ≈ 6 с). Модели меньше 2B разведчик не берёт — они путают
объявления. Интерес, который ставит модель, ничего не решает: находку продвигают только реальные цены. А
модель для фото — на игровом ПК, когда он включён. Выключен ПК — выгодное ждёт проверки фото до
`ai.vision_wait_minutes` минут, потом приходит с пометкой «фото не проверены». Включается в **Настройки → Нейросеть →
Разведчик** (кнопка «Проверить разведчика» покажет, сколько объявлений в час он успеет). Как это устроено и цифры
скорости — в `docs/design/AI_SCOUT.md`.

## Команды

| Команда | Что делает |
|---|---|
| `python -m ebeyparser setup` | мастер настройки: город, радиус, категории, бюджет, «для себя», интервал, нейросеть, Telegram |
| `python -m ebeyparser run` | веб-панель + мониторинг 24/7 (основной режим); `--server` — для сервера без экрана |
| `python -m ebeyparser access [local\|lan\|tailscale]` | ссылки на панель для телефона + QR-код; с параметром — кому открыта панель |
| `python -m ebeyparser server-models [--pull]` | какие нейросети потянет этот сервер; `--pull` — скачать их в Ollama |
| `python -m ebeyparser categories [--location Berlin] [--radius 30] [--live]` | номера категорий Kleinanzeigen; `--live` — сверить с сайтом и показать число объявлений |
| `python -m ebeyparser once` | одна проверка всех поисков и лучшие находки в консоли |
| `python -m ebeyparser check <ссылка>` | «брать или нет?» — оценить одно объявление (`--purpose personal --target 300` — для себя) |
| `python -m ebeyparser monitor` | только мониторинг, без сайта |
| `python -m ebeyparser ai-check [--fix]` | проверить локальную модель |
| `python -m ebeyparser test-notify` | отправить тестовое уведомление |
| `python -m ebeyparser benchmark` | проверка качества оценки на синтетическом рынке (без интернета) |
| `python -m ebeyparser debug-search` / `debug-ad <ссылка>` | что парсер видит на странице (если находит 0 объявлений) |
| `python -m ebeyparser ebay-limits` | лимиты запросов твоего ключа eBay |
| `python -m ebeyparser demo` | демо-данные для просмотра интерфейса |
| `python -m ebeyparser init` | просто скопировать `config.example.yaml` → `config.yaml` и `.env` |

Общие опции: `-c путь/к/config.yaml`, `-v` (подробный лог).

## Свои поиски

Кроме категорий можно искать по словам (`query`), по готовой ссылке с kleinanzeigen.de (`url`) или в eBay — на странице «Поиски» в панели или в `config.yaml`:

```yaml
  - name: "Для себя: RTX 3090 для AI-сервера"
    query: rtx 3090
    location: Berlin
    radius_km: 30
    purpose: personal
    target_price: 550     # сколько готов заплатить
    max_price: 660        # показывать и чуть дороже — с продавцом можно поторговаться
```

`pricing.reference_prices` (справочник цен) заполняй **только если точно знаешь рынок** — без него цена считается по истории и аналогам, это надёжнее. Если справочная цена сильно расходится с рынком, в причинах оценки появится предупреждение «⚠ reference_price расходится с рынком».

## eBay API (необязательно)

1. Зарегистрируйся на **[developer.ebay.com](https://developer.ebay.com)** (бесплатно) и открой **[developer.ebay.com/my/keys](https://developer.ebay.com/my/keys)**.
2. Создай **Production keyset**. eBay попросит ответить на требование **Marketplace Account Deletion** (уведомления об удалении аккаунтов): выбери исключение (exemption) **«I do not persist eBay data»** — иначе ключи не активируются. EbeyParser не сохраняет личные данные пользователей eBay (имена продавцов не записываются, только объявления и цены), так что это исключение подходит.
3. Впиши в `.env`:
   ```
   EBAY_CLIENT_ID=<App ID (Client ID)>
   EBAY_CLIENT_SECRET=<Cert ID (Client Secret)>
   ```
   Токен программа получает и обновляет сама. Лимиты ключа: `python -m ebeyparser ebay-limits` (обычно 5 000 запросов в день).

> Никогда не публикуй `.env` и токены. `.env` уже в `.gitignore`.

## Проверка после запуска (первые 1–2 дня)

- **Первая проверка** каждого нового поиска только изучает цены — уведомлений нет. Это нормально.
- **Служебные сообщения** в Telegram/на почту (`notifications.health_alerts`): «нейросеть недоступна», «Kleinanzeigen заблокировал — пауза до …», «страница сайта изменилась, объявления не читаются». Получил такое — загляни на страницу «Статус».
- **Утренний отчёт** в 9:00 (`notifications.heartbeat_hour`): «жив, проверено N объявлений, найдено M». Нет отчёта — значит, программа или компьютер не работали.
- **«⚠ ФОТО НЕ ПРОВЕРЕНЫ ИИ — проверь сам»**: нейросеть была недоступна, но по ценам это выгодно (`notifications.unchecked_deals`). Смотри фото и описание сам, прежде чем писать продавцу.
- **«Торгуйся: предложи X € → прибыль ≈ Y €»**: по цене в объявлении невыгодно или впритык, но в цене «VB» — прибыль посчитана для предложенной цены.
- Если выгодного много, больше `notifications.max_alerts_per_hour` в час не придёт — остальное соберётся в одну сводку.
- **Первые уведомления проверь руками**: открой объявление, сравни с похожими на kleinanzeigen.de и eBay. Если программа ошибается в одну сторону (завышает рынок, пропускает дефекты), поправь `pricing.min_profit`, категории или исключения — и напиши, что было не так.

## Работа 24/7 на Windows

- `deploy\start-windows.bat` перезапускает программу после сбоя, сам чинит сломанное окружение `.venv` и доустанавливает пакеты, когда ты обновил программу.
- В Windows клик мышкой внутри окна консоли включает «выделение» (QuickEdit), и программа замирает. Программа сама отключает это в своём окне; если окно всё же «замерло», нажми Esc. Отключить навсегда: правый клик по заголовку окна → Свойства → снять «Выделение мышью».
- Пока идёт мониторинг, компьютер не уходит в сон (экран гаснуть может).
- Лог пишется в `data\logs\ebeyparser.log` (5 файлов по 5 МБ).
- Второй экземпляр не запустится — программа скажет, что уже работает (два экземпляра удвоили бы запросы).
- **Не держи папку программы в OneDrive**: синхронизация блокирует и портит базу. При запуске будет предупреждение.

**Автозапуск без окна (Планировщик заданий)** — в PowerShell, поправь путь:

```powershell
$dir = "C:\EbeyParser"
$action = New-ScheduledTaskAction -Execute "$dir\.venv\Scripts\pythonw.exe" -Argument "-m ebeyparser run" -WorkingDirectory $dir
$trigger = New-ScheduledTaskTrigger -AtLogOn
$settings = New-ScheduledTaskSettingsSet -RestartCount 999 -RestartInterval (New-TimeSpan -Minutes 1) `
  -ExecutionTimeLimit ([TimeSpan]::Zero) -AllowStartIfOnBatteries -DontStopIfGoingOnBatteries
Register-ScheduledTask -TaskName "EbeyParser" -Action $action -Trigger $trigger -Settings $settings
```

`pythonw` работает без окна: панель — http://localhost:8000, всё остальное — в логе. Остановить: `Stop-ScheduledTask EbeyParser`.

**Docker / Linux / мини-ПК:** см. [«Установка на домашний сервер (24/7)»](#установка-на-домашний-сервер-247).

### Панель с телефона

По умолчанию панель открыта **только на этом компьютере** (`web.host: 127.0.0.1`). Переключается в панели: **Настройки → Доступ с телефона** (или `python -m ebeyparser access lan|tailscale|local`).

- **Лучший способ — [Tailscale](https://tailscale.com)** (бесплатно): поставь его на компьютер и телефон и выбери «Через Tailscale». Панель будет доступна только твоим устройствам, из любой сети; при запуске программа напечатает ссылку с ключом для телефона. Имена вида `…ts.net` работают сами.
- `web.host: 0.0.0.0` открывает панель **всей локальной сети**. Тогда вход только по ссылке с ключом: программа печатает её при запуске (`http://192.168.x.y:8000/?token=…`), ключ лежит в `data/web_token.txt`, браузер запоминает его после первого входа. **Не делай так в общем Wi-Fi** (общежитие, кафе, коворкинг).

## Установка на домашний сервер (24/7)

Слабого домашнего сервера хватает: мини-ПК на N100, старый ноутбук или Raspberry Pi 5, 4–8 ГБ памяти, без видеокарты. Он круглосуточно проверяет объявления и присылает в Telegram «🔥 Супер-находку» и «Топ за день», а панель ты открываешь с телефона и ПК. Сама программа занимает ~100 МБ памяти. Выбери один путь — всё остальное (город, категории, Telegram, нейросеть) настраивается потом в панели.

### Путь 1. Docker (Linux: Ubuntu, Debian, Raspberry Pi OS)

```bash
curl -fsSL https://get.docker.com | sh && sudo usermod -aG docker $USER   # один раз, потом перезайди
git clone https://github.com/Maksym706/EbeyParser EbeyParser && cd EbeyParser
docker compose up -d
docker compose logs ebeyparser        # здесь ссылка для телефона и QR-код
```

С маленькой нейросетью-разведчиком на процессоре сервера — вместо `docker compose up -d`:

```bash
docker compose --profile ai up -d
```

Программа сама выберет модель под память сервера (Qwen3.5 2B; при 16 ГБ — 4B, если в файл `.env` рядом добавить `OLLAMA_MEM_LIMIT=6g`), скачает её вместе с Qwen3-Embedding 0.6B (~2 ГБ, плюс ~3 ГБ сам образ Ollama) и включит разведчика. Ограничения памяти в `docker-compose.yml` рассчитаны на 4–8 ГБ. Панель работает на адресе самого сервера, поэтому этот путь — для Linux; на Windows бери путь 3.

### Путь 2. Linux без Docker

```bash
git clone https://github.com/Maksym706/EbeyParser ~/EbeyParser && cd ~/EbeyParser
bash deploy/install-linux.sh              # окружение Python + автозапуск (systemd), спросит пароль sudo
bash deploy/install-linux.sh --with-ai    # по желанию: Ollama и модели под этот сервер (сначала покажет план)
```

Нужен Python 3.11+ (в Debian 12 и Raspberry Pi OS уже есть; Ubuntu 22.04: `sudo apt install python3.11 python3.11-venv`). Скрипт можно запускать повторно, `--dry-run` только покажет, что он сделает. В конце он печатает ссылку для телефона и QR-код. Лог: `journalctl -u ebeyparser -f`.

### Путь 3. Windows (мини-ПК)

1. Как в «Быстром старте»: дважды кликни `deploy\start-windows.bat`.
2. Автозапуск — Планировщик заданий (раздел «Работа 24/7 на Windows»). Если у мини-ПК нет монитора, включи в Windows автоматический вход, чтобы задача стартовала после перезагрузки.
3. В панели: **Настройки → Доступ с телефона** → «Через Tailscale» или «Домашний Wi-Fi» → перезапуск.

### Первый запуск: телефон и ПК

На сервере без экрана программа при первом запуске сама открывает панель для сети и пишет в лог:

```
📱 Открой http://192.168.178.40:8000/?token=… на телефоне или ПК (домашняя сеть)
📱 Открой http://100.101.102.103:8000/?token=… на телефоне или ПК (Tailscale)
   Или наведи камеру телефона на QR-код:
```

Открой ссылку **с ключом** (`?token=…`) один раз — браузер его запомнит, и дальше мастер настройки идёт прямо на телефоне.

- **Tailscale — лучший вариант** (бесплатно): поставь на сервер (`curl -fsSL https://tailscale.com/install.sh | sh && sudo tailscale up`) и на телефон, войди в один аккаунт. Ссылка «Tailscale» работает и дома, и в дороге, и только для твоих устройств.
- **Домашний Wi-Fi**: ссылка «домашняя сеть» работает только дома. Дай серверу постоянный адрес в роутере (FritzBox: «Diesem Netzwerkgerät immer die gleiche IPv4-Adresse zuweisen»).
- Порт 8000 на роутере в интернет **не открывай** — для доступа снаружи есть Tailscale.
- Потерял ссылку: `python -m ebeyparser access` (Docker: `docker compose exec ebeyparser python -m ebeyparser access`). Сменить ключ или режим — **Настройки → Доступ с телефона**.

### Большая нейросеть на игровом ПК

Фото лучше проверяет модель побольше на игровом ПК с LM Studio:

1. На ПК в LM Studio загрузи модель (например Qwen3.5 9B), вкладка **Developer → Settings → «Serve on Local Network»**, затем **Start Server**. Если Windows спросит — разреши LM Studio в брандмауэре для частной сети.
2. В панели сервера: **Настройки → Нейросеть → «Другой сервер»**: сервер «LM Studio», адрес `http://<IP-ПК>:1234/v1` (с Tailscale — `http://<имя-ПК>:1234/v1`), модель — как в LM Studio. Кнопка «Проверить» покажет, видит ли сервер ПК.
3. **ПК выключен — ничего страшного.** Разведчик на сервере продолжает читать объявления, выгодное ждёт проверки фото до 45 минут, потом приходит с пометкой «⚠ ФОТО НЕ ПРОВЕРЕНЫ ИИ — проверь сам». Включишь ПК — проверки продолжатся сами.

### Обновление и резервная копия

- **Docker:** `git pull && docker compose up -d --build` (с нейросетью: `docker compose --profile ai up -d --build`).
- **Linux:** `bash deploy/update-linux.sh` — копия базы в `data/backups/` (три последние), новая версия, пакеты, перезапуск.
- **Windows:** как в «Обновлении с прошлой версии».
- **Резервная копия:** **Настройки → Данные и бэкап → Резервная копия** — zip с базой и настройками. Храни его не на сервере. Как восстановить, написано в `README.txt` внутри архива; в Docker распакуй архив в папку `backup` рядом и выполни:
  ```bash
  docker compose stop ebeyparser
  docker compose run --rm --no-deps -v "$PWD/backup:/restore:ro" ebeyparser \
    sh -c 'rm -f /app/data/*.sqlite3-wal /app/data/*.sqlite3-shm && cp /restore/config.yaml /restore/data/* /app/data/ && cp /restore/.env /app/data/ 2>/dev/null; true'
  docker compose start ebeyparser
  ```

## Советы по перепродаже

- Лучшие сделки уходят за минуты — включи Telegram.
- **VB** (Verhandlungsbasis) — продавец готов торговаться; программа подскажет, до какой цены это выгодно.
- Смотри на `⚠` в карточке: «Nur Tausch», «Vorkasse», iCloud-блокировка, «defekt» — почти всегда пропуск.
- Проверяй товар при встрече (видеокарта под нагрузкой, аккумулятор ноутбука, iCloud на iPhone).
- Частные продавцы на Kleinanzeigen и eBay.de обычно не платят комиссию (проверь актуальные условия и поправь `pricing.selling_fee_percent`). Если продаёшь много и регулярно, это уже Gewerbe — учитывай налоги.

## Важно

Инструмент для личного использования. Kleinanzeigen не любит автоматические запросы: не ставь слишком частые проверки и много категорий сразу. Для eBay используется официальный API.
