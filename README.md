# EbeyParser

Круглосуточный охотник за выгодными б/у вещами на **Kleinanzeigen** (и **eBay.de** через официальный API).

Выбираешь город, радиус, категории (телефоны, ноутбуки, консоли, комплектующие…) и бюджет — программа сама просматривает **все новые объявления этих категорий** рядом с тобой и для каждого перспективного:

1. **оценивает рыночную цену** — по истории цен, которую копит сама, и по похожим объявлениям на Kleinanzeigen;
2. **показывает фото и описание локальной нейросети** (LM Studio или Ollama, у тебя на компьютере, бесплатно): что это за товар, совпадают ли фото с описанием, нет ли дефектов, блокировок, признаков развода или фото из интернета;
3. **считает чистую прибыль при перепродаже** (или экономию, если покупаешь для себя) и **до какой цены стоит торговаться**;
4. **присылает в Telegram или на почту** только то, что правда стоит купить, с объяснением почему.

Два режима: **перепродажа** (купить дёшево → продать по рынку) и **для себя** (например, собрать AI-сервер из б/у железа дешевле рынка).

> Всё работает **локально**: парсер и нейросеть — на твоём компьютере. Облачная модель (Claude) — необязательное «второе мнение», по умолчанию выключено.

## Быстрый старт (Windows)

1. Установи **Python 3.11+** с [python.org](https://www.python.org/downloads/) — при установке отметь **«Add python.exe to PATH»**.
2. Скачай проект (зелёная кнопка **Code → Download ZIP**) и распакуй, например, в `C:\EbeyParser` (не в OneDrive — см. ниже).
3. Дважды кликни `deploy\start-windows.bat`. Он сам поставит всё нужное, запустит **мастер настройки** и потом панель.

Или то же самое в PowerShell:

```powershell
cd C:\EbeyParser
python -m venv .venv
.venv\Scripts\activate
pip install -e .

python -m ebeyparser setup      # мастер: город, радиус, категории, бюджет, нейросеть, Telegram
python -m ebeyparser run        # панель http://localhost:8000 + проверки 24/7
```

**Мастер настройки** (2 минуты) спрашивает по-русски: город или индекс, радиус (по умолчанию 30 км), какие категории сканировать (номера через запятую, по умолчанию — набор для перепродажи), цель, максимальную цену за вещь, минимальную прибыль, список «для себя» (например «RTX 3090» до 550 €), как часто проверять, сам находит LM Studio/Ollama и vision-модель, и (по желанию) подключает Telegram. Токены пишутся в `.env`, а не в `config.yaml`; комментарии в `config.yaml` сохраняются, старая версия — в `config.yaml.bak`.

То же самое есть в панели: страница **«Настройка»** (http://localhost:8000/setup), а нейросеть, Telegram и пороги выгоды — на вкладке рядом (`/settings`).

Хочешь сначала просто посмотреть интерфейс? `python -m ebeyparser demo`, затем `python -m ebeyparser run --no-monitor`.

## Как это работает

```
 категории в радиусе (Kleinanzeigen) ─┐
 «для себя»: RTX 3090 до 550 €       ─┼─► новые объявления ─► фильтр (Suche/Tausch/defekt, цена, мусор)
 eBay (официальный API, по желанию)  ─┘        │
                                               ▼  воронка: дальше только перспективные
                            оценка рынка: своя история цен → похожие объявления (→ продажи eBay, если доступны)
                                               │
                                               ▼
                            страница объявления (текст + все фото) → локальная нейросеть
                                               │
                                               ▼
                            прибыль, ROI, «выгодно до X €», оценка 0–100, вердикт
                                               │
                              ┌────────────────┼───────────────┐
                              ▼                ▼               ▼
                         веб-панель        Telegram          e-mail
```

- **Первая проверка нового поиска — «разведка»**: программа изучает цены в категории и **не присылает уведомлений** о том, что уже висело на сайте. Уведомления начинаются со следующей проверки — только о новых объявлениях.
- Повторно объявления не присылаются; при **снижении цены на 10 %+** объявление оценивается заново.
- Проданные на eBay (`use_ebay_sold_comps`) — хороший ориентир, но eBay часто закрывает эти страницы защитой (HTTP 403). Тогда программа просто обходится без них.

## Сканирование категорий

Главный режим — не поиск по словам, а **все новые объявления категории** в радиусе от города. В `config.yaml` это выглядит так (мастер пишет это сам):

```yaml
searches:
  - name: "Handy & Telefon · Berlin 30 км"
    location: Berlin
    radius_km: 30
    category_id: 173
    min_price: 50          # отсекает чехлы и кабели
    max_price: 400         # твой бюджет на одну вещь
    exclude_keywords: [defekt, bastler, suche, tausch, ersatzteil]
```

Номера категорий: `python -m ebeyparser categories` (встроенный справочник, без запросов к сайту). `python -m ebeyparser categories --live` сверяет его с сайтом для твоего города и показывает число объявлений (1–2 запроса, результат запоминается на 7 дней в `data/categories.json`); в панели — кнопка «Сверить с сайтом».

Рекомендуемый набор для перепродажи: Handy & Telefon (173), Notebooks (278), Konsolen (279), PC-Zubehör & Software (225), Foto (245), Audio & Hifi (172), Tablets & Reader (285).

Категория — это сотни объявлений, поэтому работает **воронка**: дешёвые проверки для всех, дорогие (страница объявления, поиск аналогов, нейросеть) — только для перспективных, в пределах лимитов за проверку (`general.max_details_per_run`, `max_comps_lookups_per_run`, `max_ai_per_run`). Не влезшее не теряется — оценится в следующей проверке. Каждая увиденная цена попадает в **историю цен**, поэтому со временем оценка точнее и требует меньше запросов.

### Сколько запросов делает мой конфиг

За одну проверку: **по странице выдачи на каждый поиск** (× `max_pages`) — это обязательно, плюс страницы и поиск аналогов **только для перспективных** объявлений (не больше `max_details_per_run + max_comps_lookups_per_run`). Сверху всё ограничено `general.max_requests_per_hour` (по умолчанию 150 в час).

Пример: 7 категорий + 1 поиск «для себя», проверка раз в 20 минут → 24 страницы выдачи в час (~576 в сутки) + проверка перспективных, всего не больше 150 в час. Мастер и страница «Настройка» показывают эту оценку для твоих настроек и предлагают безопасный интервал (не меньше 10 минут, ~2 минуты на поиск).

### Если Kleinanzeigen заблокирует

При блокировке (HTTP 403/429, капча) программа **делает паузу, и она растёт**: 1 ч → 2 ч → 4 ч → 12 ч (`general.block_cooldown_hours`). Пауза переживает перезапуск, так что перезапуск не «пробивает» блокировку. Если блокировки повторяются — увеличь `interval_minutes` и уменьши число категорий.

## Локальная нейросеть

### LM Studio (рекомендуется)

1. Установи **[LM Studio](https://lmstudio.ai)**. Во вкладке **Discover** скачай **Qwen2.5-VL-7B-Instruct** (для слабого ПК — версия 3B или Gemma 3 4B).
2. Загрузи модель и поставь **Context Length не меньше 8192** (три фото занимают много токенов).
3. Вкладка **Developer → Start Server** (или `lms server start`). В настройках включи автозапуск сервера, чтобы всё работало 24/7.
4. Мастер `setup` найдёт сервер сам. Вручную в `config.yaml`:
   ```yaml
   ai:
     enabled: true
     provider: openai
     base_url: http://localhost:1234/v1
     model: qwen/qwen2.5-vl-7b
   ```
5. Проверка: `python -m ebeyparser ai-check` (покажет модели на сервере; `--fix` сам впишет найденную vision-модель).

### Ollama (альтернатива)

```bash
ollama pull qwen2.5vl:7b
```
и в `config.yaml`: `provider: ollama`, `base_url: http://localhost:11434`, `model: qwen2.5vl:7b`.

| Твоё железо | Модель | Примерно памяти |
|---|---|---|
| Видеокарта 10–12 ГБ | Qwen2.5-VL-7B (лучшее качество, понимает немецкий) | 8–10 ГБ; на 8 ГБ поставь `max_images: 2` |
| Видеокарта 6–8 ГБ | Gemma 3 4B или MiniCPM-V | 5–8 ГБ |
| Слабый ПК / без видеокарты | Qwen2.5-VL-3B | 4–5 ГБ; на процессоре 1–3 минуты на объявление, поставь `timeout_seconds: 400` |
| 16–24 ГБ (например, RTX 3090) | Gemma 3 12B или Qwen2.5-VL-32B | 11–24 ГБ |

## Команды

| Команда | Что делает |
|---|---|
| `python -m ebeyparser setup` | мастер настройки: город, радиус, категории, бюджет, «для себя», интервал, нейросеть, Telegram |
| `python -m ebeyparser run` | веб-панель + мониторинг 24/7 (основной режим) |
| `python -m ebeyparser categories [--location Berlin] [--radius 30] [--live]` | номера категорий Kleinanzeigen; `--live` — сверить с сайтом и показать число объявлений |
| `python -m ebeyparser once` | одна проверка всех поисков и лучшие находки в консоли |
| `python -m ebeyparser check <ссылка>` | «брать или нет?» — оценить одно объявление (`--purpose personal --target 300` — для себя) |
| `python -m ebeyparser monitor` | только мониторинг, без сайта |
| `python -m ebeyparser ai-check [--fix]` | проверить локальную модель |
| `python -m ebeyparser test-notify` | отправить тестовое уведомление |
| `python -m ebeyparser benchmark` | проверка качества оценки на синтетическом рынке (без интернета) |
| `python -m ebeyparser debug-search` / `debug-ad <ссылка>` | что парсер видит на странице (если находит 0 объявлений) |
| `python -m ebeyparser ebay-limits` | лимиты запросов твоего ключа eBay |
| `python -m ebeyparser demo` | демо-данные для просмотра интерфейса |
| `python -m ebeyparser init` | просто скопировать `config.example.yaml` → `config.yaml` и `.env` |

Общие опции: `-c путь/к/config.yaml`, `-v` (подробный лог).

## Свои поиски

Кроме категорий можно искать по словам (`query`), по готовой ссылке с kleinanzeigen.de (`url`) или в eBay — на странице «Поиски» в панели или в `config.yaml`:

```yaml
  - name: "Для себя: RTX 3090 для AI-сервера"
    query: rtx 3090
    location: Berlin
    radius_km: 30
    purpose: personal
    target_price: 550     # сколько готов заплатить
    max_price: 660        # показывать и чуть дороже — с продавцом можно поторговаться
```

`pricing.reference_prices` (справочник цен) заполняй **только если точно знаешь рынок** — без него цена считается по истории и аналогам, это надёжнее. Если справочная цена сильно расходится с историей, программа предупредит.

## eBay API (необязательно)

1. Зарегистрируйся на **[developer.ebay.com](https://developer.ebay.com)** (бесплатно) и открой **[developer.ebay.com/my/keys](https://developer.ebay.com/my/keys)**.
2. Создай **Production keyset**. eBay попросит ответить на требование **Marketplace Account Deletion** (уведомления об удалении аккаунтов): для личного использования выбери исключение (exemption) **«I do not persist eBay data»** — иначе ключи не активируются.
3. Впиши в `.env`:
   ```
   EBAY_CLIENT_ID=<App ID (Client ID)>
   EBAY_CLIENT_SECRET=<Cert ID (Client Secret)>
   ```
   Токен программа получает и обновляет сама. Лимиты ключа: `python -m ebeyparser ebay-limits` (обычно 5 000 запросов в день).

> Никогда не публикуй `.env` и токены. `.env` уже в `.gitignore`.

**Telegram** (удобнее всего, приходит с фото): мастер `setup` или страница «Настройка» → Telegram.
1. Напиши [@BotFather](https://t.me/BotFather) → `/newbot` → получишь токен.

3. Кнопка «Тест» или `python -m ebeyparser test-notify`.

**Почта (Gmail):** включи двухэтапную аутентификацию, создай «пароль приложения» на [myaccount.google.com/apppasswords](https://myaccount.google.com/apppasswords), впиши в `.env` `SMTP_USER`, `SMTP_PASSWORD`, `NOTIFY_EMAIL`, в `config.yaml` — `notifications.email.enabled: true`.

Порог — `notifications.min_score` (0–100) и `notifications.verdicts` (`[buy]` или `[buy, maybe]`).

## Работа 24/7 на Windows

- `deploy\start-windows.bat` перезапускает программу после сбоя и сам чинит сломанное окружение `.venv`.
- **Не кликай мышкой внутрь окна консоли**: в Windows это включает «выделение» (QuickEdit), и программа замирает, пока не нажмёшь Enter. Отключить: правый клик по заголовку окна → Свойства → снять «Выделение мышью».
- Пока идёт мониторинг, компьютер не уходит в сон (экран гаснуть может).
- Лог пишется в `data\logs\ebeyparser.log` (5 файлов по 5 МБ).
- Второй экземпляр не запустится — программа скажет, что уже работает (два экземпляра удвоили бы запросы).
- **Не держи папку программы в OneDrive**: синхронизация блокирует и портит базу. При запуске будет предупреждение.

**Автозапуск без окна (Планировщик заданий)** — в PowerShell, поправь путь:

```powershell
$dir = "C:\EbeyParser"
$action = New-ScheduledTaskAction -Execute "$dir\.venv\Scripts\pythonw.exe" -Argument "-m ebeyparser run" -WorkingDirectory $dir
$trigger = New-ScheduledTaskTrigger -AtLogOn
$settings = New-ScheduledTaskSettingsSet -RestartCount 999 -RestartInterval (New-TimeSpan -Minutes 1) `
  -ExecutionTimeLimit ([TimeSpan]::Zero) -AllowStartIfOnBatteries -DontStopIfGoingOnBatteries
Register-ScheduledTask -TaskName "EbeyParser" -Action $action -Trigger $trigger -Settings $settings
```

`pythonw` работает без окна: панель — http://localhost:8000, всё остальное — в логе. Остановить: `Stop-ScheduledTask EbeyParser`.

**Docker / Linux:** `docker compose up -d` (см. `docker-compose.yml`) или systemd — [`deploy/ebeyparser.service`](deploy/ebeyparser.service).

### Панель с телефона

По умолчанию панель открыта **только на этом компьютере** (`web.host: 127.0.0.1`).

- **Лучший способ — [Tailscale](https://tailscale.com)** (бесплатно): поставь его на компьютер и телефон и впиши в `config.yaml` `web.host:` адрес компьютера в Tailscale (`100.x.y.z`, виден в приложении Tailscale). Панель будет доступна только твоим устройствам, из любой сети; при запуске программа напечатает ссылку с ключом для телефона. Если открываешь по имени `…ts.net`, добавь его в `.env`: `EBEYPARSER_ALLOWED_HOSTS=<имя>.ts.net`.
- `web.host: 0.0.0.0` открывает панель **всей локальной сети**. Тогда вход только по ссылке с ключом: программа печатает её при запуске (`http://192.168.x.y:8000/?token=…`), ключ лежит в `data/web_token.txt`, браузер запоминает его после первого входа. **Не делай так в общем Wi-Fi** (общежитие, кафе, коворкинг).

```yaml
ai:
  second_opinion:
    enabled: true
    model: claude-opus-5
    api_key: ${ANTHROPIC_API_KEY}
    min_score: 70      # только то, что локальная модель уже оценила высоко

```

Локальная модель по-прежнему оценивает всё, Claude перепроверяет только лучших кандидатов (платно).

## Советы по перепродаже

- Лучшие сделки уходят за минуты — включи Telegram.
- **VB** (Verhandlungsbasis) — продавец готов торговаться; программа подскажет, до какой цены это выгодно.
- Смотри на `⚠` в карточке: «Nur Tausch», «Vorkasse», iCloud-блокировка, «defekt» — почти всегда пропуск.
- Проверяй товар при встрече (видеокарта под нагрузкой, аккумулятор ноутбука, iCloud на iPhone).
- Частные продавцы на Kleinanzeigen и eBay.de обычно не платят комиссию (проверь актуальные условия и поправь `pricing.selling_fee_percent`). Если продаёшь много и регулярно, это уже Gewerbe — учитывай налоги.

## Важно

Инструмент для личного использования. Kleinanzeigen не любит автоматические запросы: не ставь слишком частые проверки и много категорий сразу. Для eBay используется официальный API.

## Для разработчиков

```bash
pip install -e ".[dev]"
python -m pytest -q
python -m ebeyparser benchmark     # качество оценки на синтетическом рынке
```

Структура: `ebeyparser/scraper` (Kleinanzeigen HTML, категории, eBay API), `pricing` (оценка цены, прибыль, фильтры), `ai` (локальная vision-модель, опционально Claude), `notify` (почта, Telegram), `web` (FastAPI-панель, мастер настройки, безопасная запись конфига), `monitor.py` (конвейер), `runtime.py` (лог, один экземпляр, режим 24/7), `cli.py`.
